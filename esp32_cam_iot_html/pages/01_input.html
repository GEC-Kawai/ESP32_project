課題名

ESP32-CAM 簡易IoT監視システム

システム目的

Freenove ESP32 Kit Dev CAM Board Ultimate Starter Kitを使用し、カメラ、センサー、LED、ブザー、Web側中継サーバを連携させた簡易IoT監視システムを構築する。

本システムは、周囲の状態をセンサーで監視し、条件成立時にカメラ撮影、状態通知、Web画面表示を行う。

利用者

利用者内容

レビュー担当者設計書、ソースコード、テスト結果を確認する
利用者PCのブラウザからWeb側中継サーバへアクセスし、ESP32状態を確認する

システムの基本動作

起動時

  1. 電源投入後、ESP32を初期化する。
  2. Wi-Fiへ接続する。
  3. カメラを初期化する。
  4. センサー、LED、ボタン、ブザーを初期化する。
  5. Web側中継サーバへTCPソケット接続する。
  6. helloメッセージを送信する。
  7. 監視状態へ遷移する。

監視中

  1. センサー値を周期的に取得する。
  2. 人や物体の検知状態を判定する。
  3. 明るさを判定する。
  4. statusメッセージとしてWeb側中継サーバへ送信する。
  5. LEDで通常状態を表示する。

センサー検知時

  1. 人感センサーまたは距離センサーで検知する。
  2. 明るさ条件を確認する。
  3. 撮影条件が成立した場合、カメラで静止画を取得する。
  4. ブザーを短く鳴らす。
  5. statusまたはcapture_resultでWeb側へ状態を通知する。
  6. 監視状態へ戻る。

Web画面からの手動撮影時

  1. Web側中継サーバからcapture_requestを受信する。
  2. 撮影可能状態か確認する。
  3. カメラで静止画を取得する。
  4. capture_resultを送信する。
  5. statusを更新して送信する。

異常時

Wi-Fi接続失敗、カメラ初期化失敗、センサー初期化失敗、TCP接続失敗、カメラ撮影失敗などの場合、ERROR状態へ遷移し、errorメッセージでWeb側へ通知する。

撮影条件の前提

  1. 監視状態であること。
  2. 人感センサーまたは距離センサーで検知ありと判定されること。
  3. 明るさセンサー値が、設計で定義した閾値条件を満たすこと。
  4. 直前の撮影から一定時間以上経過していること。
