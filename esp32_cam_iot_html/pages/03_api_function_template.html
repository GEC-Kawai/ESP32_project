内部API仕様

Wi-Fi Manager

関数名概要戻り値
wifi_manager_initWi-Fi機能を初期化する成功/失敗
wifi_manager_connect指定SSIDへ接続する成功/失敗
wifi_manager_is_connected接続状態を返すtrue/false

Socket Client Manager

関数名概要戻り値
socket_client_initソケット通信設定を初期化する成功/失敗
socket_client_connectWeb側中継サーバへ接続する成功/失敗
socket_client_sendメッセージを送信する送信結果
socket_client_receiveメッセージを受信する受信結果
socket_client_closeソケットを切断するなし
socket_client_is_connected接続状態を返すtrue/false
socket_client_reconnect再接続を試みる成功/失敗

Camera Manager
