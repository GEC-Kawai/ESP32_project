Node.jsインストール手順

Web側環境を起動するには、PCにNode.jsをインストールする必要がある。公式サイトからLTS版をインストールすることを推奨する。

https://nodejs.org/en/download

バージョン確認

node -v
npm -v

Windowsの場合

  1. 公式サイトを開く。
  2. Windows用のLTS版インストーラをダウンロードする。
  3. ダウンロードした .msi ファイルを実行する。
  4. 基本的にはデフォルト設定でよい。
  5. npm package manager と Add to PATH が有効になっていることを確認する。
  6. PowerShellまたはコマンドプロンプトを新しく開き直し、node -v と npm -v を実行する。

macOSの場合

公式インストーラを使用する。Homebrewを使用している場合は以下でもよい。

brew install node

Linuxの場合

Linux環境ではディストリビューション標準のパッケージマネージャでもインストールできるが、バージョンが古い場合がある。Node.js公式サイトの手順に従ってLTS版を入れることを推奨する。

事前準備

1. Zipを展開する

esp32_socket_relay_web.zip を任意の作業フォルダに展開する。

esp32_socket_relay_web/
  server.js
  package.json
  public/
    index.html
    styles.css
    app.js
  tools/
    mock_esp32.js
  README.md

2. ターミナルでフォルダへ移動する

cd esp32_socket_relay_web

3. パッケージをインストールする

npm install

起動手順

npm start

起動すると、以下のようなログが表示される。

TCP socket server listening on 0.0.0.0:5000
Web server listening on http://localhost:3000

ブラウザで以下を開く。

http://localhost:3000

ESP32実機なしで動作確認する方法

中継サーバを起動した状態で、別ターミナルを開き、以下を実行する。

npm run mock:esp32

成功すると、Web画面上でESP32が接続中になり、状態が周期的に更新される。

ESP32から接続する場合

項目値
接続先IP中継サーバを起動しているPCのIPアドレス
TCPポート5000
通信形式JSON Lines
区切り改行コード \n

例: 192.168.1.10:5000

PCのIPアドレス確認方法

Windows

ipconfig

macOS / Linux

ifconfig

または

ip addr

通信メッセージ例

hello

{"type":"hello","device_id":"esp32-cam-001","fw_version":"0.1.0"}

status

{"type":"status","state":"MONITORING","wifi_connected":true,"motion_detected":false,"light_level":1234,"capture_count":3,"last_capture_result":"OK","error_code":0}

capture_request

{"type":"capture_request","request_id":"req-0001"}

capture_result

{"type":"capture_result","request_id":"req-0001","result":"OK","capture_count":4,"error_code":0}

ポート変更方法

Windows PowerShell

$env:HTTP_PORT=3001
$env:TCP_PORT=5001
npm start

macOS / Linux

HTTP_PORT=3001 TCP_PORT=5001 npm start

よくあるトラブル

Web画面が開けない

  • npm start が実行中か
  • http://localhost:3000 を開いているか
  • ポート3000を別アプリが使っていないか

ESP32が接続中にならない

  • ESP32がPCのIPアドレスへ接続しているか
  • TCPポート5000を指定しているか
  • PCのファイアウォールでブロックされていないか
  • ESP32とPCが同一ネットワークにいるか

statusが表示されない

  • ESP32がstatusメッセージを送っているか
  • JSONの末尾に改行コード \n が付いているか
  • JSONの形式が正しいか

動作確認チェックリスト

  • npm install が成功する
  • npm start でサーバが起動する
  • http://localhost:3000 が開ける
  • npm run mock:esp32 でモック接続できる
  • Web画面でESP32接続中と表示される
  • statusが周期的に更新される
  • 撮影要求ボタンでcapture_requestが送信される
  • capture_resultがWeb画面に反映される
  • ESP32実機からTCP接続できる
  • ESP32実機からstatusを送信できる
