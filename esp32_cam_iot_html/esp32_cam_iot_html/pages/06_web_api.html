この資料の位置づけ

本資料は、渡邉側で支給するWeb画面およびWeb API仕様である。ただし、現在の主方針ではWeb側中継サーバを提供し、受講者はESP32側のTCPソケット通信を実装する。したがって本資料はWeb画面側の表示項目や支給範囲を確認する補足資料として扱う。

役割分担

項目担当内容
Web画面の基本構成渡邉側簡易HTML、表示項目、画面遷移を支給する
Web側中継サーバ渡邉側ブラウザとESP32間を中継する
ESP32側ソケット実装受講者JSON Lines形式で送受信する
センサー値反映受講者statusメッセージへ反映する
カメラ撮影処理受講者capture_requestに応じて撮影する
