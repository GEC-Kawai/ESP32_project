Web側一式とESP32間のTCPソケット通信仕様

この資料の位置づけ

本資料は、Web側一式とESP32間のソケット通信インターフェース仕様を定義する。本課題では、Web画面およびWeb側中継サーバは渡邉側で提供する。受講者は、ESP32側でTCPソケット通信を設計・実装し、センサー状態、カメラ撮影、エラー状態をWeb側へ連携する。

方針

ブラウザ単体では、ESP32と直接TCPソケット通信を行うことはできない。そのため、本課題ではWeb側中継サーバを経由する。

全体構成

flowchart LR Browser[Web画面
提供済み] -->|HTTP / WebSocket| Relay[Web側中継サーバ

役割分担

項目担当内容
Web画面渡邉側状態表示、撮影ボタン、画面更新
Web側中継サーバ渡邉側ブラウザ通信、ESP32とのTCPソケット通信を中継
TCPソケット接続受講者ESP32からWeb側中継サーバへ接続する
状態通知受講者ESP32から状態JSONを送信する
撮影要求受信受講者Web側からの撮影要求を受信する
撮影応答受講者撮影結果を返す
エラー通知受講者ESP32側の異常状態を通知する

通信方式

項目内容
通信方式TCPソケット
接続方向ESP32 → Web側中継サーバ
通信形式JSON Lines形式を基本とする
文字コードUTF-8
区切り文字改行コード \n
再接続切断時はESP32側で再接続を試みる

JSON Lines形式

1メッセージを1行のJSONとして送信する。送信時は末尾に改行コード \n を付与する。

{"type":"status","state":"MONITORING","wifi_connected":true,"motion_detected":false,"light_level":1234,"capture_count":3,"last_capture_result":"OK","error_code":0}

項目値備考

Web画面ポート3000Web側提供物に依存

メッセージ種別

type方向内容
helloESP32 → Web側接続開始通知
statusESP32 → Web側状態、センサー値通知
capture_requestWeb側 → ESP32撮影要求
capture_resultESP32 → Web側撮影結果通知
errorESP32 → Web側エラー通知
heartbeat双方向接続維持確認

helloメッセージ

TCP接続確立直後に送信する。

{
  "type": "hello",
  "device_id": "esp32-cam-001",
  "fw_version": "0.1.0"
}
項目型必須内容
typestring必須hello固定
device_idstring必須デバイス識別子
fw_versionstring任意ファームウェアバージョン

statusメッセージ

現在状態、センサー値、撮影状態、エラー情報を通知する。1秒周期を目安とする。

{
  "type": "status",
  "state": "MONITORING",
  "wifi_connected": true,
  "motion_detected": false,
  "light_level": 1234,
  "capture_count": 3,
  "last_capture_result": "OK",
  "error_code": 0
}
項目型必須内容
typestring必須status固定
statestring必須現在状態
wifi_connectedboolean必須Wi-Fi接続状態
motion_detectedboolean必須センサー検知状態
light_levelnumber必須明るさセンサー値
capture_countnumber必須撮影回数
last_capture_resultstring必須NONE、OK、NG、BUSY
error_codenumber必須正常時0

capture_requestメッセージ

{
  "type": "capture_request",
  "request_id": "req-0001"
}

capture_resultメッセージ

正常時

{
  "type": "capture_result",
  "request_id": "req-0001",
  "result": "OK",
  "capture_count": 4,
  "error_code": 0
}

異常時

{
  "type": "capture_result",
  "request_id": "req-0001",
  "result": "NG",
  "capture_count": 3,
  "error_code": 201,
  "message": "Camera capture failed"
}

errorメッセージ

{
  "type": "error",
  "state": "ERROR",
  "error_code": 200,
  "message": "Camera initialization failed"
}
